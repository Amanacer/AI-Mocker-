## 🪄 **Overview**
> **AI-Mocker** ek smart web application hai jo **AI** ka use karke aapko realistic interview environment deta hai.  
Dynamic questions, instant feedback & skill-based evaluation — all in one place!  

---

## ✨ **Features**
- 🧠 **AI-Generated Questions** based on your chosen topics & difficulty  
- 📊 **Instant Feedback** with performance score  
- 🎯 **Topic-Wise Customization** for technical & behavioral rounds  
- 📱 **Responsive UI** (mobile & desktop friendly)  
- ⚡ **Fast & Scalable** backend with AI model integration  

---

## 🛠 **Tech Stack**
Frontend:  React.js / Next.js
Backend:   Node.js + Express
Database:  MongoDB / PostgreSQL
AI Engine: OpenAI API / Hugging Face
Deploy:    Vercel / Render / Railway

⚙ Installation

# Clone the repository
git clone https://github.com/Amanacer/AI-Mocker-.git

# Navigate to project folder
cd AI-Mocker-

# Install dependencies
npm install

# Add environment variables in .env
OPENAI_API_KEY=your_api_key_here
MONGO_URI=your_db_connection_here

# Run the application
npm run dev
